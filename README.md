# floci-setup
quick setup for each mock cloud provider (aws, azure and google cloud) using floci.

# how to run
Just run the cloud provider you want to test using the corrispective script:
- run_aws.sh: init the aws mock environment
- run_azure.sh: init the azure mock environment
- run_gcp.sh: init the google cloud provider mock environment

To run aws environment for example:
```
bash run_aws.sh

```
